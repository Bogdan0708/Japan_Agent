# Second external audit (2026-08-28) — findings and resolutions

An independent audit of commit `985bbc0` verified the clean checkout and the
exact test gate, then compared the implementation against current broker,
messaging, AI-security, data-licensing, and performance-reporting sources.
Resolutions landed in commit `25b0891` (46 tests green).

| # | Finding | Resolution |
|---|---|---|
| 1 | T212 compliance premise too confident: model choosing target_weight is algorithmic order-parameter determination; human approval alone doesn't resolve clause 4.2(a); consent reply must affirmatively address 4.2(a) + 6.7, not be a ticket number; live gate can only verify a string exists | `COMPLIANCE.md` rewritten to require an affirmative written reply archived under `docs/consent/`; live remains code-blocked. **Open**: send the request, await the reply |
| 2 | Yahoo returns London pence as "GBp"; uppercasing → treated as £ → 100× error; tests used synthetic GBX only | `normalize_currency_code()` maps pence spellings before uppercasing, applied at adapter/importer/collector; regression test uses real "GBp" spelling. **Fixed** |
| 3 | End-to-end paper loop absent: execution consumes hand-prepared portfolio JSON; no live T212 portfolio mapper or execution worker | Deliberately deferred until real demo payloads exist (guessing the mapping would fake a green risk gate). **Open by design** — first task after demo credentials |
| 4a | Daily EDINET queried "yesterday" UTC, missing today's Tokyo filings | `daily.sh` ingests today's AND yesterday's Tokyo-calendar dates. **Fixed** |
| 4b | Freshness gate checked retrieval time only; old data re-fetched looked fresh | Gate now also checks `observed_through` (J-Quants exempt; future windows allowed). **Fixed** |
| 4c | J-Quants never scheduled; Sunday job only rendered a pre-made report | `weekly.sh` refreshes J-Quants from `config/jquants-codes.json` at a weekday-adjusted ~13-week lag, runs a deep research pass, verifies the ledger. **Fixed** (TDnet/news digests remain assistant-produced — open) |
| 4d | Decision file could be left empty by failed redirection; no run lock | Temp file + JSON validation + atomic rename; `flock` on both scripts. **Fixed** |
| 5 | Long-poll asked Telegram to wait 50s but client timed out at 15s; getUpdates conflicts with a registered webhook | Client timeout = poll wait + 10s; poller calls deleteWebhook on startup. **Fixed** |
| 6 | Top-100 research items selected globally; busy EDINET days crowd out other sources | Per-source quotas (EDINET 35 / TDNET 30 / NEWS 25 / JQUANTS 10). **Fixed** (no ticker filter: EDINET codes ≠ T212 tickers) |
| 7 | Evidence was unverified prose; hallucinated citations undetectable | `[SOURCE:external_id]` citation format enforced by output schema + prompt, deterministically verified against the DB; unknown citations block the proposal. **Fixed** |
| 8 | Third-party text embedded in prompt → indirect prompt-injection surface | Snapshot wrapped in `<untrusted-data>` markers with an explicit ignore-embedded-instructions rule; model still has zero tools. **Mitigated** (screening layer possible later) |
| 9 | Weekly return subtracted all flows from ending NAV — wrong for mid-week flows | Modified Dietz with day-weighted dated flows; benchmarks defined as GBP total-return over the identical period. **Fixed** |
| 10 | Ledger hash-chained but mutable; no verifier or external anchor | UPDATE/DELETE-blocking triggers + `verify-chain` command (weekly job runs it); git history becomes the external anchor once publishing starts. **Fixed** |
| 11 | `doctor` checked only six conditions | Expanded to twelve: data-symbol coverage, Telegram/Anthropic/data-source keys, `.env` permissions, chain integrity. **Fixed** |
| 12 | yfinance is unofficial/personal-use; not sole price authority, no republication | Documented in `COMPLIANCE.md`; broker-side fresh-portfolio preflight already independent. **Accepted** |
| 13 | "Revolutionary technology" mandate: add a distinct frontier sleeve, don't loosen the core | `FRONTIER` sleeve sharing the £15 satellite cap (engine + test); `MANDATE-GUIDANCE.md` with the seven-point candidate checklist and Japan's 2026 innovation-strategy theme list as research leads only. **Done** |
